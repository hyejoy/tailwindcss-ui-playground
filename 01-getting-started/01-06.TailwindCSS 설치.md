# tailwindcss-ui-playground

Tailwind CSS 학습 기록 - Jimcoding 'TailwindCSS 완벽 마스터' 강의 기반 - 포트폴리오 / 어드민 UI 실습 중심

## 설치 순서

### 0. npx create-next-@app15 ./

- devTime 프로젝트와 동일한 개발환경으로 구성

### 1. npm install tailwindcss @tailwindcss/postcss postcss

### 2. tailwind.config 파일 (postcss.config.mjs) 생성

### 3. src/app/globals.css 에서 Tailwind를 불러오는 코드 작성

```tsx
/* src/app/globals.css */
@import "tailwindcss";

/* 6강에서 배운 커스텀 테마 설정 */
@theme {
  --color-clifford: #da373d;
}
```

### 4. src/app/layout.tsx 파일 상단에 css파일 import 확인

```tsx
// src/app/layout.tsx
import "./globals.css"; // 이 경로가 맞는지 확인하세요

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

## Tailwind v4의 특징

- tailwind.config.js 파일은 필요 없습니다.
  **모든 설정(컬러, 폰트 등)은 globals.css의 @theme 블록 안에서 해결**합니다.
- 약 VSCode에서 자동완성이 안 된다면, Tailwind CSS IntelliSense 확장 프로그램을 최신 버전으로 업데이트
